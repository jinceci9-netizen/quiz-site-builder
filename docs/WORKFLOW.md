# 零代码工作流：用户参与共创

默认先设计，确认后自主开发。已有明确选择直接沿用，不重复提问。

1. **创意方向**：AI 提供 2～3 个差异化切口、受众和一句话亮点，推荐其一；最多问 1～2 个关键问题。
2. **测试机制**：展示评分或状态算法、结果类型、结局条件以及 2～3 道完整示例题，说明选项取舍；最多问 1～2 个关键问题。
3. **视觉体验**：展示 2～3 个具体视觉方向，包含配色、字体、手机流程和 3:4 分享图；给出一份结果报告样稿；最多问 1～2 个问题，包含最终方案确认。
4. **记录决策**：每阶段区分“已确认”“待确认建议”“剩余决策”。修改时同步记录，只回访受影响的设计。确认后写入网站 `docs/DESIGN.md`。
5. **自主开发**：设计确认或明确委托后，完成全部题库、评分算法，再复制 starter 到独立站点，完成页面、报告与分享图。不要修改 Skill 的模板。
6. **验证与预览**：运行题库校验、远程资源审查、npm install、npm test、npm run build，并验证手机布局、返回续答、不同结局、PNG 与链接。如实区分通过与未完成的检查。
7. **按需发布**：用户要求时，将网站代码保存到独立 GitHub 仓库，再通过 Cloudflare Pages Git 集成部署：main、npm run build、dist。Skill 仓库与网站仓库不同。仅本地请求不上传、不部署。
8. **大陆访问**：使用本地静态资源；正式上线后实测域名、HTTPS、运营商与设备，不保证常规 Cloudflare Pages 的大陆可访问性。

## 随时调整参与程度

- “跳过这一步”：仅本阶段采用 AI 建议并记为委托，继续下一阶段。
- “你决定剩下的”：AI 记录剩余选择，自主完成开发。
- “直接做 / 一键生成 / 你来决定”：跳过三阶段问答，说明默认选择后直接完成内容、开发、测试和本地预览。
- “回到共创”：恢复讨论，保留已有决策。
- 未回复时等待，不默认确认。以上方式均不扩大部署授权。

默认免费匿名、不做登录、付费或卡密。兼容不同 Agent：自然语言即可参与，不依赖 Codex 专属表单或工具。

## 用户提示词示例

```text
请使用 quiz-site-builder 技能与我共创一个网站，先给我2～3个创意切口。
主题：测测你在幻想国度能生存到第几章
机制：10题的剧情分支，至少 5 个可达到的不同结局
要求：不要靠选择最安全答案就一路通关；保证不同选择真的影响状态。
设计：移动端优先、沉浸式故事感、有 3:4 分享图。
部署：GitHub 单独建站点仓库，再使用 Cloudflare Pages Git 集成上线。
大陆访问：本地资源打包、避开运行时外部字体/CDN；部署后给我实测清单。
不用收费、登录或卡密，但告诉我以后如何扩展卡密。
先逐阶段讨论创意、机制与视觉并记录决策；我确认后再自主完成题库、算法、网页、测试与构建。
```
